# Contributing to MAGINALIA Collector / MAGINALIA Collectorへの貢献

## 歓迎すること

- バグ報告、機能提案、ドキュメントの改善、コードの整理・リファクタリング
- フォークで加えた改善の取り込み提案。フォークの該当コミットやブランチを指すissueでも、PRでも歓迎します。
- 継続して貢献してくれる方には、コントリビュータとしてリポジトリへ招待することがあります。

## 進め方

1. 大きな変更は、先にissueで方針を相談してください。
2. PRは `main` ブランチに向けてください（変更される場合があります。READMEとissueを確認してください）。
3. 1つのPRでは1つの目的に絞ってください。

## ライセンス

- MAGINALIA Collector は [MIT License](LICENSE) で配布されます。貢献されたコードも、同じMIT Licenseで公開されることに同意したものとして扱います。CLA（貢献者許諾契約）への署名は不要です。
- 他人が書いたコードや、ライセンスが不明なコードは含めないでください。AIツールで生成したコードは、内容を確認し、提出する権利があるものだけにしてください。
- 名称とロゴの扱いは [TRADEMARKS.md](TRADEMARKS.md) を参照してください（フォーク版は別の名前にしてください）。

## English

We welcome bug reports, proposals, documentation, refactoring, and upstream proposals of improvements made in forks. Open an issue or a pull request; for forks, pointing to the relevant commits or branch is enough. Regular contributors may be invited as collaborators.

- Pull requests target `main` (may change; check the README and issues).
- MAGINALIA Collector is licensed under the [MIT License](LICENSE). Contributions are accepted under the same license; no CLA is required.
- Do not submit code you do not have the right to submit. If you used AI tools, review the output and make sure you may submit it.
- Follow [TRADEMARKS.md](TRADEMARKS.md) regarding the name and logo; give a fork a different name.
