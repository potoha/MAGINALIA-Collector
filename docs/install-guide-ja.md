# MAGINALIA Collector 導入ガイド（Chrome・Windows）

このガイドは、Chrome Web Storeを使わずにCollectorを導入する手順です。1つの手順で1つの操作だけを行います。

## 用意するもの

- Windows版のGoogle Chrome
- GitHub ReleasesにあるCollectorの配布ZIP（`maginalia-collector-<版>.zip`）と`SHA256SUMS`
- 本棚に保存する場合: MAGINALIA連携プログラムのインストーラーと、MAGINALIA（保存先の本棚の設定に使います）

## A. Collectorを入れる

### 手順1　配布ZIPをダウンロードする

GitHubのCollectorのReleasesページを開き、`maginalia-collector-<版>.zip` と `SHA256SUMS` をダウンロードします。

`TODO(screenshot): Releasesページのファイル一覧（ZIPとSHA256SUMSの位置）`

### 手順2　（任意）ZIPが正しいか確かめる

PowerShellを開き、ダウンロードしたフォルダーで次を実行します。

```powershell
Get-FileHash .\maginalia-collector-<版>.zip -Algorithm SHA256
```

表示された値が、`SHA256SUMS` に書かれた値と一致することを確かめます。一致しない場合は、そのZIPを使わずにダウンロードし直してください。

### 手順3　ZIPを展開する

ZIPファイルを右クリックし、「すべて展開」を選びます。展開先は、今後も消さずに置いておけるフォルダーにしてください（例: ドキュメントの中）。Chromeは毎回このフォルダーから拡張機能を読み込みます。

`TODO(screenshot): エクスプローラーの「すべて展開」`

展開したフォルダーを開き、すぐ下に `manifest.json` があることを確かめます。

`TODO(screenshot): manifest.json が直下にあるフォルダー`

### 手順4　Chromeの拡張機能の画面を開く

Chromeのアドレスバーに `chrome://extensions` と入力し、Enterキーを押します。

リンクをクリックしても開かない場合は、`chrome://extensions` をコピーしてアドレスバーに貼り付けてください。

### 手順7　展開したフォルダーを選ぶ

手順3で展開した、`manifest.json` が直下にあるフォルダーを選び、「フォルダーの選択」を押します。ZIPファイルそのものは選べません。

### 手順8　一覧に追加されたことを確かめる

一覧に「MAGINALIA Collector」が表示されることを確かめます。表示されたIDが次と一致することも確かめてください。

```text

```

IDが異なる場合、そのCollectorは連携プログラムに接続できません。配布ZIPから展開し直してください。

### 手順9　ツールバーに固定する

ツールバーのパズル型の「拡張機能」ボタンを押し、MAGINALIA Collector の横のピンを押します。

### 手順10　「はじめに」画面を確認する

初めて導入したときは、Collectorの「はじめに」画面（MAGINALIA Collector の準備）が自動で開きます。ここには次の3つが表示されます。

- 拡張機能の状態
- MAGINALIA連携プログラムの状態
- 保存先の本棚の名前

この画面はツールバー画面の「準備状況と設定の案内を開く」からも開けます。

<a id="identity-mismatch"></a>

## D. 識別子が一致しないとき

「識別子が一致しません」と表示された場合、MAGINALIAに設定された本棚と、いま見つかった本棚が別のものと判断されています。本棚のフォルダーを移動・差し替え・復元したときなどに起こります。誤った本棚に書き込まないよう、Collectorは確認できるまで保存しません。

### 手順16　MAGINALIAで保存先を確認し直す

手順13〜14と同じ画面で、表示された本棚が正しいかを確認し直します。正しくない場合は、本棚のフォルダーを元に戻すか、MAGINALIAで正しい本棚を設定してください。

### 手順17　「もう一度確認」を押す

Collectorの「はじめに」画面で「もう一度確認」を押します。

## E. 引用を保存する

### 手順18　文章を選んで「本棚に追加」を選ぶ

Webページで引用したい文章を選び、右クリックして「本棚に追加」を選びます。

`TODO(screenshot): 右クリックメニューの「本棚に追加」`

### 手順19　内容を確認して「本棚に保存」を押す

確認画面で、出典・引用本文・コメントを確かめてから「本棚に保存」を押します。保存中は「保存中…」と表示されます。「保存しました」と表示されれば完了です。

`TODO(screenshot): 確認画面の「本棚に保存」と「保存しました」`

保存できなかったときは、原因と対処が表示されます。引用はこのブラウザー内に保留されて残ります。後でツールバー画面の「保留を開く」から開き、「本棚に保存」を押すと、もう一度保存できます。同じ引用を何度保存しても、本棚に二重には保存されません。

「本棚には保存済みですが、この端末の保留が残っています」と表示された場合は、本棚への保存は完了しています。もう一度「本棚に保存」を押すか、ツールバー画面から保留を削除してください。

## 更新するとき

1. 新しい配布ZIPをダウンロードし、手順2で確かめます。
2. 今使っているフォルダーの中身を、新しいZIPを展開した中身で置き換えます。フォルダーの場所は変えません。
3. `chrome://extensions` でMAGINALIA Collectorの更新ボタン（円形の矢印）を押します。
4. ツールバー画面を開き、保留中の引用が残っていることを確かめます。

**拡張機能の「削除」は押さないでください。** 削除すると、このブラウザーに保留中の引用も消えます。本棚に保存済みの引用は消えません。

## うまくいかないとき

| 症状 | 確かめること |
| --- | --- |
| 「マニフェスト ファイルが見つからない」などと表示されて読み込めない | ZIPを展開したか。選んだフォルダーのすぐ下に `manifest.json` があるか（1つ上や1つ下のフォルダーを選んでいないか） |
| `chrome://extensions` が開かない | アドレスバーに直接入力するか、コピーして貼り付けたか |
| 一覧のIDが `blgmoddncpknfnikdfnjelmdmphfgknf` と違う | 配布ZIP以外から読み込んでいないか。配布ZIPから展開し直す |
| 「未登録です」のまま | 手順11の連携プログラムを入れたか。入れた後に「もう一度確認」を押したか |
| 「未設定です」のまま | 手順13〜14でMAGINALIAの保存先を確定したか |
| 「識別子が一致しません」 | D. の手順で保存先を確認し直す |
| 「本棚をほかの処理が使用中」 | 少し待ってから、もう一度保存する |

Chrome以外のブラウザー（Edgeなど）は、現時点では対象外です。
