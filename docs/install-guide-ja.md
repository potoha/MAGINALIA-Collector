# MAGINALIA Collector 導入ガイド（Chrome・Windows）

## はじめに

> **Collector 0.3.0 に対応する版の MAGINALIA Desktop は、まだリリースされていません。**
> 公開されている MAGINALIA Desktop（`v0.1.0-alpha.1`）には、Collector 連携の設定画面（「Collector 連携を設定…」）がありません。
> そのため現在は、拡張機能を Chrome に読み込むところまでしかできません。「本棚に保存」は、対応する版の MAGINALIA Desktop が公開されるまで使えません。

このガイドの状態は**下書き**です。実際の Chrome と MAGINALIA Desktop では、まだ検証していません。画面の画像はまだありません。`TODO(screenshot)` の箇所は、実際の画面を撮影して差し替えます。画面の表示名は Chrome の版や言語で変わることがあるため、撮影時に本文も実際の表記に合わせて直します。

このガイドは、Chrome Web Store を使わずに Collector を導入する手順です。1つの手順で1つの操作だけを行います。

### 導入のしかた

| 方法 | 使える時期 | できること |
| --- | --- | --- |
| A. MAGINALIA Desktop から設定する（通常の方法） | 対応する版の公開後 | 連携プログラムの登録、保存先の確認、拡張機能の読み込みの案内、接続確認まで |
| B. 配布 ZIP から手動で入れる | 今 | 拡張機能を Chrome に読み込む。連携プログラムは入らないため、本棚には保存できない |

通常は A を使います。B は、拡張機能だけを先に試したい人と、開発する人向けです。

### 用意するもの

- Windows 版の Google Chrome
- A の場合: 対応する版の MAGINALIA Desktop
- B の場合: [Releases](https://github.com/potoha/MAGINALIA-Collector/releases) にある配布 ZIP（`maginalia-collector-<版>.zip`）。SHA-256 はリリースの説明に書いてあります。

## A. MAGINALIA Desktop から設定する

対応する版の MAGINALIA Desktop が公開されてから使えます。画面の表記は、公開時に実際の画面に合わせて直します。

### 手順1　設定を始める

MAGINALIA Desktop を起動し、「ファイル」→「Collector 連携を設定…」を選びます。

`TODO(screenshot): ファイルメニューの「Collector 連携を設定…」`

### 手順2　画面の案内に従って進める

設定画面は、次の順に案内します。各画面で表示される操作を、1つずつ行ってください。

1. 使うブラウザーを選び、連携プログラムを登録する。
2. 保存先の本棚を確認する。表示された本棚が、保存したいものか確かめてから確定する。
3. 拡張機能を Chrome に読み込む。画面の［パスをコピー］または［フォルダーを開く］で、読み込むフォルダーを確認する。拡張機能のページは Chrome では自動で開かないため、アドレスをコピーして、Chrome のアドレスバーに貼り付ける。読み込み方は B の手順5〜8と同じ。
4. 接続を確認する。「読み込みました」と表示されれば完了。

画面を途中でキャンセルしても、登録済みの内容は元に戻りません。もう一度設定する場合は、同じメニューから開きます。

### 手順3　うまくいかないとき

「ファイル」→「Collector 連携の確認・修復…」を選びます。登録の状態を調べ、直せるものを直します。

## B. 配布 ZIP から手動で入れる

連携プログラムは入りません。拡張機能の読み込みまでの手順です。

### 手順1　配布 ZIP をダウンロードする

[Releases](https://github.com/potoha/MAGINALIA-Collector/releases) を開き、`maginalia-collector-<版>.zip` をダウンロードします。

`TODO(screenshot): Releasesページのファイル一覧`

### 手順2　（任意）ZIP が正しいか確かめる

PowerShell を開き、ダウンロードしたフォルダーで次を実行します。

```powershell
Get-FileHash .\maginalia-collector-<版>.zip -Algorithm SHA256
```

表示された値が、リリースの説明に書かれた SHA-256 と一致することを確かめます。一致しない場合は、その ZIP を使わずにダウンロードし直してください。

### 手順3　ZIP を展開する

ZIP ファイルを右クリックし、「すべて展開」を選びます。展開先は、今後も消さずに置いておけるフォルダーにしてください（例: ドキュメントの中）。Chrome は毎回このフォルダーから拡張機能を読み込みます。

展開したフォルダーを開き、すぐ下に `manifest.json` があることを確かめます。

`TODO(screenshot): manifest.json が直下にあるフォルダー`

### 手順4　Chrome の拡張機能の画面を開く

Chrome のアドレスバーに `chrome://extensions` と入力し、Enter キーを押します。リンクをクリックしても開かない場合は、`chrome://extensions` をコピーしてアドレスバーに貼り付けてください。

### 手順5　「デベロッパー モード」をオンにする

画面右上の「デベロッパー モード」のスイッチをオンにします。

### 手順6　「パッケージ化されていない拡張機能を読み込む」を押す

`TODO(screenshot): 「パッケージ化されていない拡張機能を読み込む」ボタン`

### 手順7　展開したフォルダーを選ぶ

手順3で展開した、`manifest.json` が直下にあるフォルダーを選び、「フォルダーの選択」を押します。ZIP ファイルそのものは選べません。

### 手順8　一覧に追加されたことを確かめる

一覧に「MAGINALIA Collector」が表示されることを確かめます。表示された ID が次と一致することも確かめてください。

```text
blgmoddncpknfnikdfnjelmdmphfgknf
```

ID が異なる場合、その Collector は連携プログラムに接続できません。配布 ZIP から展開し直してください。

### 手順9　ツールバーに固定する

ツールバーのパズル型の「拡張機能」ボタンを押し、MAGINALIA Collector の横のピンを押します。

### 手順10　「はじめに」画面を確認する

初めて導入したときは、Collector の「はじめに」画面（MAGINALIA Collector の準備）が自動で開きます。拡張機能の状態、連携プログラムの状態、保存先の本棚の名前が表示されます。

連携プログラムを入れていないため、「未登録です」と表示されるのが正しい状態です。この画面は、ツールバー画面の「準備状況と設定の案内を開く」からも開けます。

## 引用を保存する

連携プログラムを登録し、保存先を設定したあとの手順です。対応する版の MAGINALIA Desktop が公開されるまでは、「本棚に保存」は使えません。

### 手順1　文章を選んで「本棚に追加」を選ぶ

Web ページで引用したい文章を選び、右クリックして「本棚に追加」を選びます。

### 手順2　内容を確認して保存する

確認画面で、出典・引用本文・コメントを確かめます。そのあと、次のどちらかを押します。

- 「本棚に保存」: 本棚に保存します。保存中は「保存中…」と表示され、「保存しました」と表示されれば完了です。
- 「このブラウザーに保留」: このブラウザーの中に置きます。本棚には送りません。

保存できなかったときは、原因と対処が表示されます。引用はこのブラウザー内に保留されて残ります。あとでツールバー画面の「保留を開く」から開き、「本棚に保存」を押すと、もう一度保存できます。同じ引用を何度保存しても、本棚に二重には保存されません。

「本棚には保存済みですが、この端末の保留が残っています」と表示された場合は、本棚への保存は完了しています。もう一度「本棚に保存」を押すか、ツールバー画面から保留を削除してください。

## 更新するとき

1. 新しい配布 ZIP をダウンロードし、B の手順2で確かめます。
2. 今使っているフォルダーの中身を、新しい ZIP を展開した中身で置き換えます。フォルダーの場所は変えません。
3. `chrome://extensions` で MAGINALIA Collector の更新ボタン（円形の矢印）を押します。
4. ツールバー画面を開き、保留中の引用が残っていることを確かめます。

**拡張機能の「削除」は押さないでください。** 削除すると、このブラウザーに保留中の引用も消えます。本棚に保存済みの引用は消えません。

## うまくいかないとき

| 症状 | 確かめること |
| --- | --- |
| 「マニフェスト ファイルが見つからない」などと表示されて読み込めない | ZIP を展開したか。選んだフォルダーのすぐ下に `manifest.json` があるか（1つ上や1つ下のフォルダーを選んでいないか） |
| `chrome://extensions` が開かない | アドレスバーに直接入力するか、コピーして貼り付けたか |
| 一覧の ID が `blgmoddncpknfnikdfnjelmdmphfgknf` と違う | 配布 ZIP 以外から読み込んでいないか。配布 ZIP から展開し直す |
| 「未登録です」のまま | 手動導入（B）では正しい状態。本棚に保存するには、対応する版の MAGINALIA Desktop で A の設定を行う |
| 「未設定です」のまま | A の保存先の確認で、本棚を確定したか |
| 「識別子が一致しません」 | 本棚のフォルダーを移動・差し替え・復元していないか。MAGINALIA Desktop の「Collector 連携の確認・修復…」で確かめる。誤った本棚に書き込まないよう、Collector は確認できるまで保存しません |
| 「本棚をほかの処理が使用中」 | 少し待ってから、もう一度保存する |

このガイドの手順は Google Chrome 向けです。Microsoft Edge など Chrome 以外のブラウザー向けの手順は、実機で確認でき次第、追加します（それまでは本ガイドの対象外です）。

複数のブラウザー（またはプロファイル）に Collector を入れると、保留中の引用を入れておく場所はそれぞれ別になり、互いに見えません。
